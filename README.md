# Fast Cargo (WIP)

A modular logistics API for managing deliveries, drivers, accounts, and notifications.  
Built with **TypeScript**, **DDD**, **Clean Architecture**, and **NestJS**.

> This project is a work in progress. The structure and features are being actively implemented.

---

## Monorepo structure
```text
├── core/ # Domain logic and use cases (framework-agnostic)
├── api/ # NestJS application exposing HTTP layer
├── package.json # Shared scripts and dependencies
├── pnpm-workspace.yaml
├── tsconfig.json
```

---

## Tech Stack

- **TypeScript** with `pnpm` workspaces
- **Domain-Driven Design (DDD)** & Clean Architecture
- **NestJS** for API layer
- **ESLint**, **Prettier**, **Jest**

---

## Status

Initial setup complete. Starting the API implementation with NestJS.
